Dying ReLU Diagnostic Tool

Neuron Status: Active
Formula: $z = w \cdot x + b$
Output: $f(z) = \max(0, z)$
What is happening? The dots represent a batch of input data. When the Bias is too negative, it pushes all inputs into the "Dead Zone" (z ≤ 0). Since the gradient of ReLU is 0 for negative values, the weights can no longer be updated during backpropagation. The neuron "dies" and stays at zero forever.
